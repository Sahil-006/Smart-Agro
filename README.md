**Smart Agro** is an intelligent, full-stack agriculture platform designed to empower farmers with data-driven insights. By combining real-time hardware monitoring, environmental data, and machine learning, the platform optimizes irrigation, predicts soil health, and prevents crop diseases, ensuring higher yields and sustainable farming practices.

## Key Features

*   **AI Crop Disease Detection:** Upload pictures of crop leaves to our AI/ML engine for instant disease identification and actionable prevention recommendations before infections spread.
*   **Centralized Dashboard:** A responsive, unified control panel for monitoring all farm metrics, hardware status, and environmental data at a glance.
*   **Smart Crop Insights:** Receive tailored crop recommendations based on current soil parameters and localized weather conditions.
*   **Soil Health Analytics:** Analyze soil conditions with machine learning predictions to maintain optimal nutrient levels for specific crops.
*   **Solar System Monitoring:** Track the efficiency and power output of solar panels used to drive smart irrigation systems.
*   **Secure Authentication:** Standard username/password login paired with seamless **OAuth integration** (Google & GitHub) for quick access.
*   **Integrated Customer Support:** A built-in messaging system enabling farmers to directly connect with agricultural experts and technical support.

## Tech Stack

**Frontend**
*   **React.js** - UI development
*   **React Router** - Client-side routing
*   **TailwindCSS / CSS** - Responsive styling
*   **Axios** - API communication

**Backend & Services**
*   **Python (Flask)** - Core backend APIs and AI/ML model serving for disease detection and soil prediction
*   **Node.js** - Asynchronous microservices and authentication handling
*   **Embedded C** - Hardware-level programming for soil sensors and solar monitoring microcontrollers

## Prerequisites
*   Node.js (v16+)
*   Python (3.8+)
*   Hardware components (for local sensor testing)
